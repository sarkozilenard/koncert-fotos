# Koncert Fotós

Zénó Varga szegedi koncert- és eseményfotós portfóliója. Letisztult, kék felület a fellépések, fesztiválok és rendezvények képeivel.

## Oldalak

- Kezdőlap
- Rólam
- Szolgáltatások: koncertfotózás, eseményfotózás, zenekari promóció
- Munkáim: fesztivál, klub, szabadtér, akusztikus
- Galéria szűrőkkel és nagyítással
- Kapcsolat: `zenovarga02@gmail.com`, Instagram `@varga.visuals`

A kapcsolat űrlap a kitöltés után a levelezőprogramban nyitja meg az üzenetet. Nincs külön szerver vagy adatbázis.

## Futtatás

```bash
npm install
npm run dev
```

A fejlesztői szerver alapból a [http://localhost:3000](http://localhost:3000) címen indul. Más port:

```bash
npx next dev -p 4317
```

## Éles build

```bash
npm run build
npm start
```
